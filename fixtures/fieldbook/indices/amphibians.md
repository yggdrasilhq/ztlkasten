# Amphibians

The running tally, and the place every crossing entry points at.

An index is not a category applied to a note from outside. It is a note like any
other, and it earns its contents by being linked — which is why it can hold an
argument as well as a list.

**The four-degree rule.** Movement tracks the first night above four degrees
rather than a calendar date. Two confirmations so far, both from the culvert,
both in one spring — not enough to promote it from a rule of thumb.
